# stage-generate

Apply [generation authority](../video-studio/references/generation.md) before any paid request. Use `ovs video-models` and `ovs video-params`, then pass exact supported `--image-urls`, `--ratio`, `--duration`, `--resolution` and `--generate-audio` values. First/last frames are for meaningful changes; one identity reference suffices for small motion. Preserve speaking-mouth audio. For recurring characters read [short films](../video-craft/references/short-film.md) and [stage-consistency](../stage-consistency/SKILL.md). Keep one aspect and a bounded shot/character count in the approved budget. A task receipt or timeout does not authorize a new output set; retain successful siblings and never silently resubmit.
