# stage-consistency

Use [short-film guidance](../video-craft/references/short-film.md). Keep one compact look line and reusable reference image per character; record visible features, wardrobe, prop identity, screen positions and first/last frame continuity. Name which reference controls each shot. Inspect adjacent frames and audio across joins. Preserve geographic and identity anchors on revision, and regenerate only the affected shot under [spending authority](../video-studio/references/generation.md). Do not pay for redundant end frames when the subject barely changes.
